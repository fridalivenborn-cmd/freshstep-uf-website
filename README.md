# FreshStep UF Website

A modern, Scandinavian-inspired website for FreshStep UF, a student-run Swedish company creating a reusable shoe bag for training shoes and other used footwear.

## Overview

This project includes a complete, responsive single-page website built with HTML, CSS, and JavaScript. It follows the requested design direction with a premium Scandinavian look, earthy green palette, subtle animations, and accessible interactions.

## Features

- Responsive navigation for desktop and mobile
- Hero section with premium positioning and call-to-action
- Problem-focused educational content
- Product presentation with clear feature highlights
- Three-step process explanation
- Activated carbon and silica gel educational visual sections
- Sustainability and company story sections
- Team member cards
- Shop/order block with placeholder pricing and order button
- Social media section with placeholders
- Contact form and contact information
- Footer with brand information and links

## Files

- `index.html` – page structure and content
- `styles.css` – modern styling, responsive design, and animations
- `script.js` – mobile menu, smooth scrolling, contact form behavior, and enhancements

## How to Run

Open `index.html` directly in a browser, or serve the folder with a local web server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

- Social links and order links are placeholders and can be replaced later.
- Product pricing uses `[PRICE] SEK` as requested.
- The design is structured to allow easy replacement of placeholder imagery with real product photos in the future.

## Customization

Update the following placeholders in `index.html` before launch:

- Contact email
- Instagram link
- TikTok link
- Order form URL
- Product price
